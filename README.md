# YaMDb

**YaMDb** — REST API для сервиса сбора отзывов пользователей на произведения.

Пользователи могут оставлять отзывы и оценки произведениям, комментировать отзывы других пользователей. На основе оценок автоматически формируется рейтинг произведения.

Произведения распределяются по категориям и жанрам. В приложении реализованы регистрация пользователей, JWT-аутентификация и разграничение доступа по ролям.

---

## Возможности

* регистрация пользователей с подтверждением по коду;
* получение JWT-токена;
* управление пользователями;
* роли пользователей: `user`, `moderator`, `admin`;
* каталог произведений, категорий и жанров;
* поиск и фильтрация произведений;
* отзывы и оценки произведений;
* автоматический расчёт рейтинга;
* комментарии к отзывам;
* разграничение прав доступа;
* импорт начальных данных из CSV;
* документация API в формате ReDoc.

## Запуск проекта

Клонируйте репозиторий:

```bash
git clone https://github.com/shibaevvv/api-yamdb.git
cd api-yamdb
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его.

Linux/macOS:

```bash
source venv/bin/activate
```

Windows:

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Перейдите в каталог Django-проекта:

```bash
cd api_yamdb
```

Выполните миграции:

```bash
python manage.py migrate
```

Запустите сервер разработки:

```bash
python manage.py runserver
```

После запуска API будет доступен по адресу:

```text
http://127.0.0.1:8000/api/v1/
```

## Основные эндпоинты

### Регистрация

```http
POST /api/v1/auth/signup/
```

Пример запроса:

```json
{
  "email": "user@example.com",
  "username": "username"
}
```

После регистрации пользователю отправляется код подтверждения.

### Получение JWT-токена

```http
POST /api/v1/auth/token/
```

```json
{
  "username": "username",
  "confirmation_code": "123456"
}
```

### Произведения

```http
GET /api/v1/titles/
```

Поддерживается фильтрация по:

* названию;
* году;
* категории;
* жанру.

### Отзывы

```http
GET /api/v1/titles/{title_id}/reviews/
POST /api/v1/titles/{title_id}/reviews/
```

Пользователь может оставить только один отзыв на каждое произведение.

Оценка задаётся по шкале от `1` до `10`. На основе оценок рассчитывается рейтинг произведения.

### Комментарии

```http
GET /api/v1/titles/{title_id}/reviews/{review_id}/comments/
POST /api/v1/titles/{title_id}/reviews/{review_id}/comments/
```

## Роли пользователей

В проекте предусмотрены три роли:

* **user** — создание и редактирование собственных отзывов и комментариев;
* **moderator** — дополнительно может изменять и удалять отзывы и комментарии других пользователей;
* **admin** — полный доступ к управлению содержимым и пользователями.

## Импорт данных из CSV

Для загрузки тестовых данных используется собственная management command.

CSV-файлы находятся в каталоге:

```text
api_yamdb/static/data/
```

Для первоначальной загрузки с очисткой существующих данных:

```bash
python manage.py load_data --wipe
```

Для добавления данных без предварительной очистки:

```bash
python manage.py load_data
```
